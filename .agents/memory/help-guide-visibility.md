---
name: Help guide visibility
description: Why coordinators can read family guides and why help filtering is not authorization.
---

Service coordinators should be able to read both the Parent / Guardian and
Self-Representing Participant guides as well as their own guide.

**Why:** CEPS wants coordinators to help families use the portal. Restricting them
to only their own guide would prevent that assistance.

**How to apply:** Keep help-guide visibility distinct from account and data
permissions. Help is public static text filtered for relevance, not an API
authorization boundary. Showing family help does not grant a coordinator family
account actions.
