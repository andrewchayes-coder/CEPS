---
name: Referral terminology
description: User-facing naming rule and the explicit exception for the Intake workflow status.
---

Use “Referral” rather than “Intake” in user-facing headings, agreements, messages, help, and signing pages. The `intake` status retains its “Intake” label in badges, filters, and the Case Status report.

**Why:** CEPS explicitly requested the wording change while preserving that workflow status label.

**How to apply:** Change display text only. Do not rename existing routes, API fields, database columns, test IDs, or the `intake` status value. Internal identifiers and private diagnostic logs may retain the old term.
